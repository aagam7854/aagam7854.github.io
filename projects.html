CodeBot v3 — Native AI Coding Assistant & Static Security Engine

Executive Summary

CodeBot v3 is a full-stack, privacy-first developer platform designed to solve the two biggest drawbacks of modern cloud-based AI coding tools: recurring API costs and code privacy leaks.

Unlike conventional coding assistants that simply wrap proprietary cloud APIs (such as OpenAI or Anthropic), CodeBot v3 is engineered around a dual-tier, 100% on-premise inference architecture. It delivers sub-millisecond, deterministic code generation for over 100+ standard computer science algorithms and full CRUD application architectures, runs automated static security audits against real-world Common Weakness Enumeration (CWE) benchmarks, and seamlessly routes arbitrary complex requests to a local open-weights LLM (Llama 3.2:3b via Ollama) — achieving complete data privacy and zero external API dependencies.

React 19 Next.js 16 (App Router) TypeScript Ollama (Llama 3.2:3b) CWE Static Scanner HTTP-Only JWT (jose) Zod Validation Repository Datastore

Key Engineering Highlights & Features

⚡

1. Dual-Tier Hybrid Inference Engine

Tier 1: Deterministic Native Engine

Analyzes developer prompts via regex and rule-based intent classifiers to generate mathematically proven, production-ready code across Python, Java, C++, C, and JavaScript. Produces tested implementations for algorithms (sorting, graph traversals, trees, dynamic programming) and multi-file management systems (college, inventory, banking) with built-in SQLite persistence in single-digit milliseconds.

Tier 2: On-Device LLM Fallback

If a query falls outside indexed templates, the system intelligently delegates the task to a locally hosted Ollama instance running llama3.2:3b. At no point does proprietary user code leave the developer's local machine.

🛡️

2. Static Code Security Audit Engine (CWE Scanner)

Features a built-in static analysis engine that parses submitted source code and benchmarks it against standard Common Weakness Enumeration (CWE) rules, outputting a formal audit scorecard:

CWE-798 Credential Leaks: Detects hardcoded passwords, tokens, and secrets in source code.
CWE-95 Code Injection: Catches dangerous arbitrary execution primitives (eval(), new Function()).
CWE-89 SQL Injection: Identifies unsanitized, concatenated SQL queries in backend strings.
CWE-835 Loops & Delimiters: Verifies bracket matching and catches infinite loops with unreachable termination.
CWE-532 Sensitive Logging: Scans console logging statements for unredacted credentials.
🔐

3. Enterprise Authentication & Quota System

  • Stateless JWT Security: Generates cryptographically signed HS256 tokens with jose, strictly transmitted inside secured, SameSite=Lax HTTP-only cookies to eliminate XSS/CSRF vectors.
  • Password Hashing: Uses bcryptjs with salted cryptographic hashes for credential persistence.
  • Token Rate-Limiting & Quota Management: Built-in token ledger that allocates a daily credit balance per user, automatically resetting on India Standard Time (IST) calendar boundaries.
  • Admin Dashboard & Telemetry: Role-Based Access Control (RBAC) granting administrators live system metrics, user audit logs, and token reset capabilities.
📦

4. Decoupled Repository Pattern & Zero-Config

Built an abstracted data-access layer (src/lib/db.ts) backed by a local JSON file datastore.

This eliminates the friction of requiring Docker, PostgreSQL, or external cloud databases for local development and academic evaluation, while preserving clean contracts that can be pointed to PostgreSQL in production without touching the API routes.
